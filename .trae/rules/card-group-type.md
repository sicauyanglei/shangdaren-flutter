# 一门牌组合状态分类

以门2（丘乙己）为例，按张数分类一门牌的各种组合状态，并定义保留价值排名。

## 分类原则

1. 每种分布按**最优拆解**命名（使结构总分最大的拆解方式）
2. 拆解组件优先级：招 > 坎 > 句 > 对 > 半靠 > 孤张
3. 命名按组成组件拼接，如"坎对孤张型" = 坎 + 对 + 孤张
4. 结构分按门2-7普字评分：招100、坎60、句50、对20、半靠10、孤张0

> 注：门1（上大人）/门8（福禄寿）含精字，组件分值不同（精招200、精坎150、金对100、精句90、精靠50、精单40、银对20、银靠10、银单0），分类名称相同但分值需替换。

## 保留价值排名

按"拆解破坏损失程度"从高到低排名，排名越高表示越不应拆解破坏。

### 排名原则

1. **完整集优先**：招 > 坎 > 句，完整集一旦拆解损失巨大且难以重组
2. **结构分为主**：结构分越高，保留价值越高
3. **进张潜力为辅**：同分时，含对/半靠（有进张潜力）的类型排名高于含孤张的类型
4. **完整集数量加成**：多个完整集的类型，保留价值指数级高于单个完整集

### 同分区分规则

当多个牌型结构分相同时，按以下规则区分保留优先级：

1. **含招 > 含坎 > 含句**：完整集质量越高越优先保留
2. **含对 > 含半靠 > 含孤张**：进张潜力越高越优先保留
3. **张数少 > 张数多**：同结构分下，用更少张数达成同等结构的类型更高效，优先保留

示例：
- 招招对型(220) vs 招坎坎型(220)：招招对型含2招 > 招坎坎型含1招，招招对型优先
- 招对孤张型(120) vs 坎坎型(120)：招对孤张型含招 > 坎坎型含坎，招对孤张型优先
- 招孤张型(100) vs 招型(100)：同含1招，招型用4张 vs 招孤张型用5张，招型更高效优先

### 门间优先级

门1（上大人）与门8（福禄寿）优先级相同，门2-7优先级相同。门间出牌优先级取决于当前主攻的胡牌类型路线：

| 胡牌类型路线 | 优先拆的门 | 优先保留的门 | 原因 |
|------------|-----------|------------|------|
| 依赖胡数的路线（普通胡、枯胡、清枯胡、清枯重台、红元） | 门2-7 | 门1/8 | 门1/8含精字（上/福），精字提供高胡数，优先保留 |
| 黑元 | 门1/8 | 门2-7 | 黑元要求无上/福、全门2-7，门1/8的精字反而阻碍路线 |
| 十对 | 无优先 | 无优先 | 十对只看对数，门1/8和门2-7同等对待 |

**门间优先级与门内优先级的关系**：

1. 先按胡牌类型路线确定门间优先级（拆哪个门）
2. 再按保留价值排名确定门内牌型优先级（拆哪个牌型）
3. 最后按门内选牌规则确定出哪张牌

**示例**：
- 普通胡路线，门2有孤张型(排名34)，门1也有孤张型(排名34) → 先拆门2的孤张
- 黑元路线，门2有孤张型(排名34)，门1也有孤张型(排名34) → 先拆门1的孤张
- 十对路线，门2和门1都有孤张型 → 任选一门拆

### 门1/8对孤张型特例

门1（上大人）/门8（福禄寿）中，当对孤张型的对为**银对**（大大/人人/禄禄/寿寿）时，**优先出对中字**而非孤张，因为保留银靠（大人/禄寿）有精句潜力（4胡），高于保留银对的普坎潜力（3胡）。

|------------|-------------|----------|---------------|----------|---------|
| 大大人 | 人 | 大大(银对)→大大大(普坎3胡) | **大** | 大人(银靠)→上大人(精句4胡) | 精句4胡 > 普坎3胡 |
| 人人大 | 大 | 人人(银对)→人人人(普坎3胡) | **人** | 人大(银靠)→上大人(精句4胡) | 精句4胡 > 普坎3胡 |
| 禄禄寿 | 寿 | 禄禄(银对)→禄禄禄(普坎3胡) | **禄** | 禄寿(银靠)→福禄寿(精句4胡) | 精句4胡 > 普坎3胡 |

### 剩余张数动态调整

以上排名和选牌优先级是**静态基准**，实际决策需根据牌面上每个字的剩余张数动态调整。

#### 剩余张数定义

每个字总数4张。**剩余张数 = 4 - 已知张数**，已知张数 = 手牌 + 组合牌 + 弃牌区 + 其他玩家组合牌。

#### 进张概率

```
进张概率 = 所需字的剩余张数 / 未知牌总数
未知牌总数 = 96 - 所有已知牌数
```

#### 组件降级规则

当组件的进张概率为0（所需字剩余0张）时，该组件降级：

| 组件 | 降级条件 | 降级为 | 原因 |
|------|---------|--------|------|
| 半靠 | 半靠中任一字剩余0张 | 两个孤张 | 无法成句，失去结构意义 |
| 对 | 该字剩余0张（已见4张） | 两个孤张（十对路线除外） | 无法成坎，对的价值仅剩十对 |
| 对 | 该字剩余1张 | 保留对，但进张概率低 | 成坎概率低，对的价值降低 |
| 孤张 | 该字剩余0张 | 死孤张 | 无法成对，完全无进张 |

**十对路线特殊处理**：十对路线下，对不降级（对本身就是目标结构），但孤张剩余0张时仍降级为死孤张。

#### 降级后的牌型重分类

组件降级后，牌型需重新归类：

| 原牌型 | 降级条件 | 重分类为 | 新结构分 |
|--------|---------|---------|---------|
| 半靠型 | 半靠中一字剩余0 | 孤张+孤张（按两个孤张型处理） | 0 |
| 对孤张型 | 对中字剩余0（非十对） | 孤张+孤张+孤张 | 0 |
| 对孤张型 | 孤张剩余0 | 对型（孤张变死孤张，优先出） | 20 |
| 句孤张型 | 孤张剩余0 | 句型（孤张变死孤张，优先出） | 50 |
| 句半靠型 | 半靠中一字剩余0 | 句+死孤张（等同句孤张型） | 50 |
| 坎孤张型 | 孤张剩余0 | 坎型（孤张变死孤张，优先出） | 60 |
| 坎半靠型 | 半靠中一字剩余0 | 坎+死孤张（等同坎孤张型） | 60 |
| 坎对型 | 对中字剩余0（非十对） | 坎+死孤张×2 | 60 |
| 坎对孤张型 | 对中字剩余0（非十对） | 坎+死孤张×2+孤张 | 60 |
| 坎对孤张型 | 孤张剩余0 | 坎对型（孤张变死孤张） | 80 |
| 招孤张型 | 孤张剩余0 | 招型（孤张变死孤张，优先出） | 100 |
| 招对型 | 对中字剩余0（非十对） | 招+死孤张×2 | 100 |
| 招半靠型 | 半靠中一字剩余0 | 招+死孤张（等同招孤张型） | 100 |

#### 进张概率对选牌的影响

同一牌型内，多个可选牌时，按进张概率排序：

| 场景 | 选择规则 |
|------|---------|
| 半靠型中选一张出 | 优先出**进张概率低**的字（剩余张数少的字） |
| 对孤张型中孤张vs对 | 孤张剩余0张时，孤张为死孤张，**优先出死孤张**；孤张剩余多时，仍优先出孤张 |
| 句半靠型中选半靠的字 | 优先出半靠中**进张概率低**的字 |
| 坎对型中选对中一张 | 对中字剩余0张时（非十对），对已降级，**优先出降级的对** |
| 多个孤张型门比较 | 优先出**死孤张**（剩余0张）所在门；都有进张时，优先出进张概率最低的孤张 |

#### 剩余张数对门间优先级的影响

门间优先级也受剩余张数影响：

| 场景 | 调整规则 |
|------|---------|
| 门1/8中精字（上/福）剩余0张 | 精字无进张，门1/8的保留价值降低，在依赖胡数路线下优先级接近门2-7 |
| 门2-7中某门所有字剩余都很少 | 该门进张困难，保留价值降低，优先拆该门 |
| 门1/8中精字剩余多 | 精字进张概率高，门1/8保留价值进一步提升 |

#### 低胡数时门1/8保护

当总胡数≤8时，门1/8的保留优先级大幅提升，甚至高于门2-7的半靠和对子：

| 当前胡数 | 门1/8保护力度 | 原因 |
|---------|-------------|------|
| 0-4 | 极强（惩罚最大） | 门1/8精字是凑胡数的唯一希望，精单4胡、精靠4胡、精句4胡 |
| 5-8 | 强 | 门1/8精字是达到11胡门槛的关键来源 |
| 9-10 | 中 | 已接近11胡门槛，门1/8仍重要但非唯一来源 |
| ≥11 | 正常 | 已满足胡数门槛，按常规门间优先级处理 |

**具体规则**：胡数≤8时，门1/8的孤张型（精单4胡）保留优先级 > 门2-7的半靠型（0胡）和对型（0胡）

**示例**：
- 6胡时，门8有福寿(精靠4胡)，门5有尔小(半靠0胡) → 优先出尔/小，保留福寿
- 4胡时，门1有上(精单4胡)，门3有化化(对型0胡) → 优先出化，保留上

**黑元路线例外**：黑元路线不需要门1/8，此保护规则不适用。

#### 动态调整总结

出牌决策的完整流程：

1. **计算剩余张数**：统计每个字的剩余张数
2. **组件降级**：剩余0张的组件按降级规则处理
3. **牌型重分类**：降级后的牌型重新归类，更新结构分
4. **低胡数保护**：胡数≤8时，门1/8保留优先级提升（黑元路线除外）
5. **按三层优先级决策**：选门 → 选牌型 → 选牌
6. **同层同分时**：优先出进张概率最低的牌（剩余张数最少的字）

### 出牌决策应用

出牌时，按三层优先级依次决策：

**第一层：选门**（门间优先级）

1. 根据胡牌类型路线，确定优先拆的门（见门间优先级表）
2. 同优先级门中，选保留价值排名最低的门

**第二层：选牌型**（门内优先级）

1. 优先拆**孤张型**门（排名34）
2. 其次拆**半靠型**门（排名33）
3. 依次往上，最后才考虑拆**含招**的门（排名1-19）

**第三层：选牌**（牌型内优先级）

1. 按牌型内选牌优先级表，选择损失最小的牌出
2. 同损失时，选择进张概率最低的牌出
