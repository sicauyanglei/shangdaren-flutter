# 困难模式AI策略规则

本规则定义困难模式下AI的综合决策体系。核心原则：**路线相关评分 + 听牌距离优先 + 死听规避 + 动态调整**。所有决策基于"操作后总分 - 操作前总分"的最大化原则。

---

# 第一部分：决策框架

## 一、决策流程总览

```
每次决策（出牌/吃碰招）的完整流程：

1. 游戏阶段判定 → 确定当前阶段（序盘/中盘/终盘）
2. 路线系统评估 → 判定主路线 + 路线资格检查 + 动态切换
3. 评分体系计算 → 组件分 + 附加分 + 协同加分
4. 核心计算 → 听牌距离 + 摸牌期望值 + 牌效 + 死听检测
5. 决策执行 → 出牌/吃碰招评分 → 选择最优操作
6. 风险评估 → 对手预测 + 防守调整 + 流局策略
```

## 二、游戏阶段划分

| 阶段 | 牌堆剩余 | 策略倾向 | 核心目标 |
| ---- | -------- | -------- | -------- |
| 序盘 | >60张 | 路线探索，出孤张 | 保留进张潜力，探索最优路线 |
| 中盘 | 30-60张 | 路线定型，集中资源 | 完成核心面子，缩短听牌距离 |
| 终盘 | <30张 | 听牌优先，防守权重提升 | 快速听牌，避免放炮 |
| 流局期 | <10张 | 防守为主，保底不输 | 减少损失，争取流局 |

### 阶段策略细则

**序盘（>60张）**：
- 优先出孤张、死孤张
- 保留所有进张潜力牌
- 路线探索期，不急于定型
- 对手预测数据积累期

**中盘（30-60张）**：
- 路线定型，集中资源
- 优先完成核心面子
- 开始关注对手出牌
- 听牌距离权重提升

**终盘（<30张）**：
- 优先听牌距离
- 防守权重提升
- 避免高风险出牌
- 死听规避权重最大

**流局期（<10张）**：
- 未听牌→放弃进攻，全力防守
- 已听牌但死听→拆听换安全牌
- 已听牌且非死听→维持听牌，出安全牌
- 胡数不足→接受流局，减少损失

# 第二部分：路线系统

## 三、胡牌路线分类

| 路线 | 触发条件 | 胡数要求 | 核心目标 | 权重 |
| ---- | -------- | -------- | -------- | ---- |
| 普通胡 | 总胡数≥11 | ≥11 | 句+坎+对组合，胡数达标 | 1.0 |
| 黑元 | 无碰无招，全门2-7，无上/福 | 无 | 6句+1靠 | 1.3 |
| 十对 | 手牌9对 | 无 | 9对+1单 | 1.5 |
| 红元 | 无碰无招，组1/8句≥2，上/福3-6张 | 无 | 门1/8精句≥2 | 1.3 |
| 枯胡 | 无吃，有上/福，手牌无单无4张，6坎+1对 | 无 | 6坎+1对 | 1.2 |
| 清枯胡 | 枯胡+全精坎 | 无 | 6精坎+1对 | 1.4 |
| 清枯重台 | 清枯胡+重台条件 | 无 | 特殊结构 | 1.6 |

## 四、路线判定与优先级

### 4.1 判定优先级

1. **十对**：手牌已有≥7对 → 十对路线
2. **黑元**：无碰无招且手牌全门2-7且无上/福 → 黑元路线
3. **红元**：无碰无招且门1/8句≥2且上/福3-6张 → 红元路线
4. **枯胡**：无吃且有上/福且手牌无单无4张 → 枯胡路线
5. **普通胡**：以上都不满足或总胡数≥11 → 普通胡路线

### 4.2 路线权重应用

当多条路线可行时，取权重最高的作为主路线：

```
全手牌总分 = Σ(各门牌型总分) × 路线权重
```

## 五、路线资格跟踪

### 5.1 十对路线资格跟踪

| 条件 | 说明 |
| ---- | ---- |
| 资格获取1 | 发牌后手牌至少6对（discards.length==0时检查） |
| 资格获取2 | 前3个回合内（discards.length≤3）手牌出现6对以上 |
| 资格失效 | 超过3个回合且未达到6对，不再考虑十对路线 |
| 资格失效 | 组合牌区已有牌（吃/碰/招），彻底放弃十对路线 |

**关键**：十对资格一旦获得，整局保留；一旦失效，整局不再考虑。

### 5.2 主动黑元策略

非纯黑元手牌也可**主动追求**黑元：

| 条件 | 说明 |
| ---- | ---- |
| 触发条件1 | 门1+门8张数≤3且总胡数≤10胡 |
| 触发条件2 | 手牌不能有招（4张同字），但允许有坎 |
| 触发条件3 | 坎所在门需有其他字，才能通过出牌把坎转化为句 |
| 触发条件4 | 已有句数+潜在句数（半靠）至少4，否则距离黑元太远 |
| 潜力值 | 50 + 句数×30 + (3-门1/8张数)×10 - 有坎时-20 |

**设计理由**：黑元给4-5番，普通胡不足11胡给0番，胡数<11时应优先黑元。

## 六、动态路线切换

### 6.1 切换触发条件

```
每次摸牌/出牌后重新评估路线：
若 新路线潜力值 > 当前路线潜力值 × 1.3 → 切换路线
路线切换有冷却期（3回合内不再切换）
```

### 6.2 路线潜力值计算

```
路线潜力值 = 路线权重 × (当前进度/目标进度) × 100 + 进张概率加成

示例：
- 黑元进度4/7句，潜力值 = 1.3 × (4/7) × 100 = 74
- 普通胡胡数8/11，潜力值 = 1.0 × (8/11) × 100 = 73
- 黑元潜力(74) > 普通胡(73) → 维持黑元
```

### 6.3 路线进度定义

| 路线 | 进度计算 | 目标进度 |
| ---- | -------- | -------- |
| 普通胡 | 当前胡数 | 11胡 |
| 黑元 | 已有句数+半靠数 | 7（6句+1靠） |
| 十对 | 已有对数 | 9对 |
| 红元 | 门1/8精句数 | 2句 |
| 枯胡 | 已有坎数 | 6坎 |

# 第三部分：评分体系

## 七、门2-7组件基础分（路线相关）

### 7.1 组件基础分表

| 组件 | 普通胡 | 黑元 | 十对 | 红元 | 枯胡 | 说明 |
| ---- | ------ | ---- | ---- | ---- | ---- | ---- |
| 招(4张同字) | 100 | 10 | 100 | 10 | 5 | 黑元/红元破坏资格；十对=2对；枯胡要求无4张 |
| 坎(3张同字) | 60 | 15 | 55 | 10 | 90 | 黑元/红元破坏资格；十对=1对+1单；枯胡核心目标 |
| 句(3字各1) | 50 | 60 | 15 | 40 | 10 | 黑元核心目标；十对无法成对；枯胡不要句 |
| 对(2张同字) | 20 | 8 | 50 | 10 | 40 | 黑元不能碰坎；十对核心目标；枯胡可碰成坎 |
| 半靠(2字各1) | 10 | 30 | 20 | 20 | 5 | 黑元可成句+1靠来源；枯胡不能成坎 |
| 孤张(1张) | 0 | 2 | 10 | 0 | 0 | 十对可凑对；枯胡要求无单 |

### 7.2 设计理由

**普通胡**：句/坎/招都是有效面子，对可碰坎(+3胡)。

**黑元**：句↑(50→60)核心目标；对↓↓(20→8)不能碰坎；坎↓(60→15)破坏资格；半靠↑(10→30)成句来源。

**十对**：对↑↑(20→50)核心目标；招=2对(100)；坎=1对+1单(55)；句↓↓(50→15)无法成对。

**红元**：句↓(50→40)不如门1/8精句；对↓(20→10)不能碰坎；坎/招↓破坏资格。

**枯胡**：坎↑↑(60→90)核心目标；对↑(20→40)可碰成坎；句↓↓(50→10)不是目标。

## 八、门1/8组件基础分（路线相关）

### 8.1 精字组件基础分

| 组件 | 胡数 | 普通胡 | 黑元 | 十对 | 红元 | 枯胡 |
| ---- | ---- | ------ | ---- | ---- | ---- | ---- |
| 精招(上上上上/福福福福) | 16 | 200 | 5 | 100 | 50 | 5 |
| 精坎(上上上/福福福) | 12 | 150 | 5 | 55 | 80 | 120 |
| 金对(上上/福福) | 8 | 100 | 5 | 50 | 70 | 50 |
| 精句(上大人/福禄寿) | 4 | 90 | 5 | 15 | 90 | 10 |
| 精靠(含上/福的2字) | 4 | 50 | 5 | 20 | 60 | 5 |
| 精单(上/福) | 4 | 40 | 5 | 10 | 50 | 5 |

### 8.2 银字组件基础分

| 组件 | 胡数 | 普通胡 | 黑元 | 十对 | 红元 | 枯胡 |
| ---- | ---- | ------ | ---- | ---- | ---- | ---- |
| 银对(大大/人人/禄禄/寿寿) | 0 | 20 | 5 | 50 | 20 | 40 |
| 银靠(大人/禄寿) | 0 | 10 | 5 | 20 | 30 | 5 |
| 银单(大/人/禄/寿) | 0 | 0 | 5 | 10 | 10 | 0 |

### 8.3 设计理由

**普通胡**：精字提供高胡数，精招200>精坎150>金对100>精句90>精靠50>精单40。

**黑元**：门1/8所有牌型统一5分，黑元要求全门2-7无上/福。

**十对**：精字银字与普字同等对待。精招=2对(100)，精坎=1对+1单(55)，金对/银对=1对(50)。

**红元**：门1/8精字是红元核心。精句90(核心目标)，精坎80，金对70，精靠60，精单50。

**枯胡**：精坎120(核心目标+12胡)，金对50(可碰成精坎)，银对40(可碰成坎)。

## 九、牌型总分计算

### 9.1 计算公式

```
门牌型总分 = 最优拆解组件分之和 + 剩余张数附加分 + 胡数附加分 + 跨门协同加分
全手牌总分 = Σ(各门牌型总分) × 路线权重
```

### 9.2 最优拆解

每门牌可能有多种拆解方式，取**组件分之和最大**的拆解。

示例（黑元路线，门5：尔尔小生，4张）：
- 拆解1：句(尔小生)60 + 孤张(尔)2 = 62
- 拆解2：对(尔尔)8 + 半靠(小生)30 = 38
- 最优拆解 = 拆解1，组件分 = 62

示例（黑元路线，门2：丘乙乙，3张）：
- 拆解1：对(乙乙)8 + 孤张(丘)2 = 10
- 拆解2：半靠(丘乙)30 + 孤张(乙)2 = 32
- 最优拆解 = 拆解2，组件分 = 32

## 十、剩余张数附加分

### 10.1 剩余张数定义

每个字总数4张。**剩余张数 = 4 - 已知张数**，已知张数 = 手牌 + 组合牌 + 弃牌区 + 其他玩家组合牌。

### 10.2 进张概率

```
进张概率 = 所需字剩余张数 / 未知牌总数
未知牌总数 = 96 - 所有已知牌数
```

### 10.3 附加分计算

```
剩余张数附加分 = Σ(每条进张路径的期望分)
单条进张路径期望分 = (进张后组件分 - 当前组件分) × 进张概率
```

### 10.4 进张路径示例

**对(乙乙)在普通胡路线**：
- 摸乙→坎：路径期望 = (60-20) × P(乙) = 40 × P(乙)
- 摸己→句(丘乙己)：路径期望 = (50-20) × P(己) = 30 × P(己)（需同门有丘）
- 附加分 = 40×P(乙) + 30×P(己)

**对(乙乙)在黑元路线**：
- 摸乙→坎：路径期望 = 0（黑元不能坎，此路径无效）
- 摸己→句(丘乙己)：路径期望 = (60-8) × P(己) = 52 × P(己)
- 附加分 = 52×P(己)

### 10.5 组件降级

| 组件 | 降级条件 | 降级为 | 影响 |
| ---- | -------- | ------ | ---- |
| 半靠 | 半靠中任一字剩余0张 | 两个孤张 | 无法成句 |
| 对 | 该字剩余0张（非十对） | 两个孤张 | 无法成坎/句 |
| 孤张 | 该字剩余0张 | 死孤张 | 完全无进张 |

降级后，牌型需重新拆解并重新计算组件分。十对路线下，对不降级。

## 十一、胡数附加分

### 11.1 仅普通胡路线

胡数附加分仅适用于普通胡路线。其他路线不受11胡限制，胡数附加分为0。

### 11.2 计算公式

```
胡数权重 = max(0, (11 - 当前胡数) / 11) × 2
胡数附加分 = 组件胡数 × 胡数权重
```

| 当前胡数 | 胡数权重 | 说明 |
| -------- | -------- | ---- |
| 0 | 2.0 | 胡数极缺，胡数贡献组件价值翻倍 |
| 5 | 1.09 | 胡数不足，胡数贡献组件有加成 |
| 8 | 0.55 | 接近门槛，胡数贡献组件仍有加成 |
| 11 | 0.0 | 胡数已够，无附加分 |

## 十二、跨门协同加分

仅普通胡路线有跨门协同加分，其他路线为0：

| 协同类型 | 胡数加成 | 分数加成 |
| -------- | -------- | -------- |
| 普对 + 句中1字 | +3 | +30 |
| 普靠 + 句中2字 | +6 | +60 |
| 普单 + 句中2字 | +3 | +30 |
| 3精句（3个相同精句） | +6 | +60 |
| 3普句（3个相同普句） | +9 | +90 |

**注意**：金对/金靠/金单不参与跨门协同加分。

# 第四部分：核心计算

## 十三、听牌距离量化

### 13.1 距离定义

```
听牌距离 = 需要的进张次数 × 进张难度系数

距离=0 → 已听牌
距离=1 → 1张进张即听
距离=2 → 2张进张即听
距离≥3 → 远离听牌
```

### 13.2 计算方法

1. 模拟移除手牌中的句/坎/招/对/靠
2. 剩余结构距离听牌的进张次数 = 距离
3. 按听牌类型（单钓听/普通听/十对听）分别计算

### 13.3 进张难度系数

| 进张字剩余张数 | 难度系数 | 说明 |
| -------------- | -------- | ---- |
| ≥3张 | 1.0 | 容易进张 |
| 2张 | 1.2 | 中等难度 |
| 1张 | 1.5 | 困难 |
| 0张 | ∞ | 死听（无法进张） |

### 13.4 距离应用

```
听牌距离优先原则：
1. 多张牌出牌后结构总分接近时，优先选听牌距离更短的出牌
2. 但若该出牌导致死听，则放弃，选听牌距离稍远但非死听的出牌
3. 已死听时，优先拆听换路，即使听牌距离变远
```

## 十四、摸牌期望值

### 14.1 计算公式

```
摸牌期望值 = Σ(每张未知牌的价值 × 该牌概率)

每张未知牌的概率 = 1 / 未知牌总数
```

### 14.2 每张未知牌的价值

| 摸到该牌的结果 | 价值 | 说明 |
| -------------- | ---- | ---- |
| 能成句/坎/对 | 该组件分 | 完成面子 |
| 能听牌 | +500 | 接近胡牌 |
| 能胡牌 | +1000 | 直接胡牌 |
| 无用牌 | 0 | 需要弃掉 |

### 14.3 吃vs摸对比

```
吃牌价值 > 摸牌期望值 × 1.2 → 吃牌（需20%溢价补偿机会成本）
吃牌价值 ≤ 摸牌期望值 × 1.2 → 摸牌
```

**设计理由**：吃牌消耗1次摸牌机会，需要20%溢价补偿。

## 十五、牌效评估

### 15.1 单张牌效计算

```
单张牌效 = 该牌在所有可能组合中的贡献分

牌效 = Σ(组合分 × 组合概率)
```

### 15.2 出牌原则

- 牌效最低的牌优先出
- 牌效相近时，出进张概率低的

### 15.3 示例

手牌"丘乙"，出丘还是出乙？
- 丘的牌效 = P(己)×句分(50) + P(丘)×对分(20) = 50×P(己) + 20×P(丘)
- 乙的牌效 = P(己)×句分(50) + P(乙)×对分(20) = 50×P(己) + 20×P(乙)
- 若P(丘) < P(乙) → 出丘（牌效更低）

## 十六、死听检测

### 16.1 死听定义

**死听**：听牌状态下，所胡牌（进张字）剩余张数为0，永远无法摸到/点炮胡牌。

### 16.2 死听判定

| 听牌类型 | 死听条件 | 说明 |
| -------- | -------- | ---- |
| 单钓听 | 所钓字剩余0张 | 单钓"丘"，但丘剩余0张 → 死听 |
| 普通听 | C集中需成坎/句的字剩余0张 | C集有对(乙乙)需摸乙成坎，但乙剩余0张 → 死听 |
| 十对听 | 所需凑对的字剩余0张 | 手牌8对+1单(丘)，需摸丘成对，但丘剩余0张 → 死听 |

### 16.3 死听惩罚

```
若 出牌后会导致死听：
  出牌评分 -= 200（死听惩罚，远大于结构分损失）

若 当前已死听：
  优先拆听换路，即使听牌距离变远
  拆听换路评分 = 换路后总分 + 100（换路奖励）
```

### 16.4 半死听

```
若 出牌后会导致半死听（剩余1张）：
  出牌评分 -= 50（半死听惩罚）
```

### 16.5 多面听优先

| 听牌类型 | 面数 | 优先级 |
| -------- | ---- | ------ |
| 双面听（2个进张字都剩余>0） | 2 | 最高 |
| 单面听（1个进张字剩余>0） | 1 | 中 |
| 死听（进张字剩余0） | 0 | 最低（应换路） |

### 16.6 单钓听评分调整

单钓听时，**点炮不可胡**（只能自摸），听牌价值降低：

```
单钓听听牌数 = 实际听牌数 × 0.5（减半评估）
单钓听进张概率 = 实际进张概率 × 0.5
```

### 16.7 听牌数对比精细化规则

| 场景 | 选择规则 | 说明 |
| ---- | -------- | ---- |
| 听牌数多2张以上 | 直接选 | 听牌数差距大 |
| 听牌数多1张 | 只要胡数不低于当前 | 听牌数优先 |
| 听牌数相同 | 进张概率更高优先 | 同等听牌数 |
| 进张概率相同 | 选胡数更高的 | 同等概率 |
| 听牌数少1张 | 需胡数显著更高(+8以上) | 牺牲听牌数需补偿 |

### 16.8 特殊胡型潜力加分

| 总胡数 | 额外加分 | 说明 |
| ------ | -------- | ---- |
| ≥20胡 | +150 | 高胡数路线 |
| ≥15胡 | +80 | 中高胡数路线 |
| <15胡 | +0 | 无额外加分 |

### 16.9 胡数资格保护

```
若 出牌前胡数≥11 且 出牌后胡数<11 且 无特殊胡牌潜力：
  跳过该出牌（不作为候选）
```

**特殊胡牌潜力**：十对、黑元、红元、枯胡潜力>0时，不受11胡限制。

# 第五部分：出牌决策

## 十七、出牌决策流程

1. **判定主路线**：根据手牌+组合牌结构，按路线判定优先级确定主路线
2. **计算当前总分**：Σ(各门牌型总分) × 路线权重
3. **遍历每张可出的牌**：计算出该牌后的总分
4. **死听检测**：检查出牌后是否导致死听/半死听，施加惩罚
5. **听牌距离计算**：计算出牌后的听牌距离
6. **防守风险评估**：计算点炮风险
7. **选择总分最高的出牌**：总分最高 = 损失最小

## 十八、出牌评分公式

```
出牌评分 = 出牌后全手牌总分
         - 出牌风险分（对手预测）
         - 死听惩罚
         - 半死听惩罚
         - 破坏完整句惩罚
         - 破坏靠惩罚
         + 路线出牌优先级加分

出牌损失 = 当前总分 - 出牌后总分
```

选择出牌评分最高的牌打出。

## 十九、出牌惩罚机制

### 19.1 破坏完整句惩罚

| 听牌距离 | 惩罚分 | 说明 |
| -------- | ------ | ---- |
| ≤2 | -400 | 接近听牌，拆句损失大 |
| ≤4 | -300 | 中等距离，拆句损失较大 |
| >4 | -200 | 距离远，拆句损失相对小 |

**动态调整**：
```
重组因子 = 1.0 - min(缺失字剩余张数 × 0.05, 0.3)
最终惩罚 = 基础惩罚 × 重组因子
```

**豁免规则**：
- 黑元路线下门1/8句：豁免惩罚
- 坎/招+靠结构：不惩罚
- 出的牌有冗余(≥2张)：不惩罚

### 19.2 破坏靠惩罚

| 靠类型 | 听牌距离≤2惩罚 | 听牌距离≤4惩罚 | 听牌距离>4惩罚 |
| ------ | ------------ | ------------ | ------------ |
| 精句潜力靠 | -(250+剩余×25)×胡数权重 | -(200+剩余×20)×胡数权重 | -(150+剩余×15)×胡数权重 |
| 精靠(含上/福) | 同上 | 同上 | 同上 |
| 普句靠 | -(150×因子) | -(100×因子) | -(50×因子) |

**胡数权重**：胡数<11时×1.5，胡数≥11时×1.0

**普句靠因子**：
```
因子 = 0.3 (缺失字剩余0张)
因子 = 1.0 - (4-缺失字剩余).clamp(0,3) × 0.1 (剩余多→因子大)
```

**对子+独立单张特例**：出单张惩罚很轻 -(10+剩余×2)

## 二十一、防守出牌策略

### 21.1 听牌后防守

```
听牌后出牌优先级：
1. 安全牌（对手已弃出的字）→ 风险0
2. 对手组合牌所在门的字 → 风险低
3. 剩余张数少的字 → 风险低
4. 绝对安全牌（所有4张已可见）→ 风险0
```

### 21.2 风险评分

```
出牌风险 = Σ(每个对手需要该字的概率 × 放炮损失)

防守阈值：
- 听牌后：出牌风险 > 100 → 选安全牌
- 已听+胡数高：出牌风险 > 50 → 选安全牌
- 未听牌：出牌风险 > 200 → 选安全牌
- 流局期：出牌风险 > 30 → 选安全牌
```

### 21.3 同分时 tiebreaker

当多张牌出牌评分相同时：
1. 优先出进张概率最低的牌（剩余张数最少的字）
2. 优先出死孤张（剩余0张）
3. 优先出非门1/8的牌（保留门1/8精字潜力，黑元路线除外）

# 第六部分：吃碰招决策

## 二十二、操作评分公式

```
操作评分 = 操作后全手牌总分 - 操作前全手牌总分
         - 牌堆消耗分(-5) - 摸牌机会成本(-8)
         + 路线进度加分
         - 破坏组件代价
```

| 操作 | 牌堆消耗分 | 摸牌机会成本 |
| ---- | ---------- | ------------ |
| 吃 | -5 | -8 |
| 碰 | -5 | -8 |
| 招 | -5 | -8 |

## 二十三、操作条件

```
若 操作评分 > 0 → 执行操作
若 操作评分 ≤ 0 → 不操作（过牌摸牌）
```

## 二十四、路线进度加分

| 操作 | 路线进度加分 | 说明 |
| ---- | ------------ | ---- |
| 吃(黑元) | +50 | 黑元需6句，吃1句=进度+1/6 |
| 碰(枯胡) | +50 | 枯胡需6坎，碰1坎=进度+1/6 |
| 碰(普通胡) | +30 | 碰坎+3胡 |
| 招(普通胡) | +40 | 招+6胡 |

## 二十五、吃牌决策

### 25.1 吃vs摸对比

```
若 吃牌价值 > 摸牌期望值 × 1.2 → 吃牌
若 吃牌价值 ≤ 摸牌期望值 × 1.2 → 摸牌
```

### 25.2 吃牌特例

- 困难模式AI：手牌有上家出的牌且手牌中有且只有这张卡牌完整的1句，不吃，自己摸牌
- 人类玩家：同上情况不显示吃/过按钮，直接摸牌

### 25.3 低胡数普通对子保护

胡数<8且不走黑元路线时，吃牌如果破坏普通对子（普对/银对，不含金对），不考虑吃，直接摸牌。例外：吃后听牌时允许吃。

### 25.4 吃牌破坏组件代价量化

| 破坏对象 | 代价分 | 说明 |
| -------- | ------ | ---- |
| 破坏句(字在A集) | **-80** | 句是完整面子 |
| 破坏坎(字在C集) | **-100** | 坎在手牌=3胡 |
| 破坏对子(字有2张) | -(20+剩余×5) | 对子可碰坎 |
| 破坏靠(同门有其他字) | -30 | 靠有成句潜力 |
| 绝版牌(剩余0张) | 额外-30 | 吃掉后无法再获得 |
| 稀缺牌(剩余1张) | 额外-15 | 吃掉后难以再获得 |

### 25.5 吃牌后听牌极大收益

```
若 吃牌后听牌：
  操作评分 = 10000（极大收益，远大于其他因素）
```

### 25.6 吃牌距离对比

| 场景 | 处理 | 说明 |
| ---- | ---- | ---- |
| 吃牌后距离≤2 | 收益+800 | 接近听牌 |
| 吃牌后距离≤4 | 收益+300 | 中等距离 |
| 吃牌后距离=吃牌前 | 收益+100 | 距离不变 |
| 吃牌后距离>吃牌前(普通路线) | 拒绝吃牌 | 距离增加 |
| 吃牌后距离>吃牌前(十对路线) | 允许吃牌 | 改善普通路线 |

### 25.7 黑元路线下吃牌优化

| 场景 | 处理 | 说明 |
| ---- | ---- | ---- |
| 吃牌后手牌形成半靠 | 优先吃 | 半靠是黑元目标结构 |
| 吃牌后既多1句又保留半靠 | 极优 | 句+半靠，更接近黑元听牌 |
| 半靠中的牌 | 不算多余牌 | 半靠是黑元目标结构 |

## 二十六、碰牌决策

### 26.1 碰牌条件

- 手牌有该字2张（对子）
- 当前牌数允许碰（19张时可以碰，20张时不能碰）

| 红元 | 不碰 | 碰破坏红元资格 |

### 27.1 招牌条件

### 28.2 孤张型判定

- **非孤张型**：该门在手牌中有2张以上牌

### 28.3 保护力度上限

| 银字(大/人/禄/寿) | **奖励+600** | 黑元要求全门2-7 |
| 门1/8非精非银字 | **奖励+550** | 清理门1/8牌 |

### 29.1 银对特例

| 对孤张型示例 | 常规出（孤张） | 特例出（对中字） | 特例优势 |
| ------------ | ------------- | --------------- | -------- |
| 大大人 | 人 | **大** | 大人(银靠)→上大人(精句4胡) > 大大大(普坎3胡) |

| ------------ | ------------- | ---- |

| 福福禄 | 禄 | 福福(金对8胡)→福福福(精坎12胡) > 精句4胡 |

**判定规则**：对孤张型中，若对为银对，出对中字保留银靠；若对为金对，出孤张保留金对。

## 三十、硬性约束

评分时必须遵守以下硬性约束（违反则评分置为-∞）：

1. **牌总数核查**：手牌+组合牌总张数在19-20之间
2. **招牌牌数规则**：19张不能招自己手牌4张，20张不能招别人出的牌，20张不能碰/吃
3. **单钓听点炮限制**：单钓听时不能胡单钓的这张字
4. **操作优先级**：胡>招>碰>吃
5. **困难模式AI吃牌特例**：手牌有完整1句时不吃
6. **低胡数普通对子保护**：胡数<8且不走黑元路线时，吃牌破坏普通对子不吃（例外：吃后听牌允许）

## 三十一、评分优先级

当多个维度冲突时，按以下优先级决策：

1. **听牌/胡牌**（最高优先级）：能听牌或胡牌时，优先听牌/胡牌
2. **死听规避**：出牌导致死听时放弃，选非死听出牌
3. **听牌距离**：听牌距离更短的出牌优先（但不能死听）
4. **胡数资格保护**：不破坏胡数资格（≥11胡不出到<11胡）
5. **门结构总分**：结构分高的拆解优先
6. **进张概率**：高概率进张优先
7. **对手预测**：高风险出牌规避
8. **胡牌类型路线**：高权重路线优先保留

# 第八部分：对手分析与流局策略

## 三十二、对手手牌预测

### 32.1 预测依据

- **弃牌区**：对手弃出的牌，说明对手不需要该字
- **组合牌区**：对手已吃/碰/招的牌，说明对手在该门有投入
- **出牌顺序**：早期出孤张，中期出多余进张，后期出防守牌
- **摸牌后出牌**：摸牌后出的牌，说明该牌对对手无用

### 32.2 预测应用

- **点炮风险评估**：出某张牌被对手吃的概率 = 对手在该门有组合牌 × 该字剩余张数 / 未知牌总数
- **防守策略**：避免出对手可能需要的字
- **进攻策略**：若对手手牌预测较弱，可激进进攻

## 三十三、深度读牌

### 33.1 对手手牌推断

1. 对手未弃出的字 → 可能在手牌中
2. 对手摸牌后未出 → 该牌有用
3. 对手组合牌所在门 → 该门有投入
4. 对手出牌顺序 → 推断手牌结构

### 33.2 听牌预测

| 对手行为 | 推断 | 应对 |
| -------- | ---- | ---- |
| 出牌变保守 | 可能已听牌 | 防守权重×2 |
| 开始出安全牌 | 确定已听牌 | 只出安全牌 |
| 弃出某门所有字 | 该门无投入 | 可出该门牌 |
| 摸牌后立即出 | 该牌无用 | 可出该牌 |

### 33.3 风险评估

```
出牌风险分 = Σ(每个对手点炮概率 × 点炮后损失分)
出牌最终评分 = 门结构评分 - 出牌风险分
```

## 三十四、流局策略

### 34.1 流局触发条件

牌堆剩余<10张进入流局期。

### 34.2 流局出牌策略

| 场景 | 策略 | 说明 |
| ---- | ---- | ---- |
| 未听牌 | 放弃进攻，全力防守 | 减少放炮风险 |
| 已听牌但死听 | 拆听换安全牌 | 死听无法胡牌 |
| 已听牌且非死听 | 维持听牌，出安全牌 | 争取自摸 |
| 胡数不足 | 接受流局，减少损失 | 保底不输 |

### 34.3 流局评分调整

| 牌堆剩余 | 防守权重 | 说明 |
| -------- | -------- | ---- |
| <10张 | ×1.5 | 流局期，防守权重提升 |
| <5张 | ×2.0 | 接近流局，全力防守 |
| <3张 | 只出绝对安全牌 | 最后阶段 |

# 第九部分：完整评分示例

## 三十五、黑元路线场景

- 路线：黑元
- 手牌：丘乙乙化化千尔尔小生八九九佳作作亡（17张）
- 组合牌：十七土（句，门4）
- 当前胡数：0

**门2（丘乙乙，3张）**：
- 最优拆解：半靠(丘乙)30 + 孤张(乙)2 = 32
- 剩余张数附加分：半靠(丘乙)摸己→句：30×P(己)
- 门2总分 ≈ 32 + 30×P(己)

**门5（尔尔小生，4张）**：
- 最优拆解：句(尔小生)60 + 孤张(尔)2 = 62
- 门5总分 ≈ 62

**出尔后**：门5=句(60)，门2=半靠+孤张(32) → 合计92
**出丘后**：门5=句+孤张(62)，门2=对(8) → 合计70

**结论**：出尔(92) > 出丘(70) → 选择出尔

## 三十六、普通胡路线对比

同样手牌，但路线为普通胡：

**门2（丘乙乙，3张）**：
- 最优拆解：对(乙乙)20 + 孤张(丘)0 = 20
- 附加分：摸乙→坎(40×P(乙))，摸己→句(30×P(己))
- 门2总分 ≈ 20 + 40×P(乙) + 30×P(己)

**门5（尔尔小生，4张）**：
- 最优拆解：句(尔小生)50 + 孤张(尔)0 = 50
- 门5总分 ≈ 50

**出尔后**：门5=句(50)，门2=对+孤张(20) → 合计70
**出丘后**：门5=句+孤张(50)，门2=对(20) → 合计70

**结论**：普通胡路线下，出尔和出丘总分接近，需看附加分细节。

# 第十部分：与旧评分体系的对比

| 维度 | 旧体系 | 新体系 |
| ---- | ------ | ------ |
| 牌型评分 | 静态排名，不随路线变化 | 路线相关，同一牌型不同路线不同分 |
| 对子评分 | 统一20分 | 黑元8分，十对50分，枯胡40分 |
| 剩余张数 | 多个函数各自计算，可能冲突 | 统一在附加分中计算 |
| 胡数影响 | 补丁式调整 | 胡数权重公式统一计算 |
| 黑元对子 | 靠补丁惩罚 | 评分本身就低，无需补丁 |
| 听牌距离 | 未量化 | 量化计算，进张难度系数 |
| 摸牌期望值 | 未计算 | 统一计算，吃vs摸对比 |
| 防守策略 | 简单规避 | 风险评分+防守阈值 |
| 流局策略 | 无 | 分阶段防守策略 |
| 决策一致性 | 多函数可能冲突 | 单一总分比较，无冲突 |
