# 门结构评分与综合决策规则

本规则定义AI在吃/碰/招/出牌决策时的综合评分体系。所有决策基于"操作后总分 - 操作前总分"的最大化原则。

## 一、一门牌的定义

一门 = 3字 × 4张 = 12张牌。全牌共8门（门1-门8）。
- 门1（上大人）、门8（福禄寿）：含精字（上/福），可组精类牌型
- 门2-7：全普字，仅普类牌型

## 二、一门牌的35种张数分布

按3字张数 (a,b,c)，a≥b≥c：

| 张数 | 分布结构 |
| ---- | -------- |
| 0 | (0,0,0) |
| 1 | (1,0,0) |
| 2 | (2,0,0)、(1,1,0) |
| 3 | (3,0,0)、(2,1,0)、(1,1,1) |
| 4 | (4,0,0)、(3,1,0)、(2,2,0)、(2,1,1) |
| 5 | (4,1,0)、(3,2,0)、(3,1,1)、(2,2,1) |
| 6 | (4,2,0)、(4,1,1)、(3,3,0)、(3,2,1)、(2,2,2) |
| 7 | (4,3,0)、(4,2,1)、(3,3,1)、(3,2,2) |
| 8 | (4,4,0)、(4,3,1)、(4,2,2)、(3,3,2) |
| 9 | (4,4,1)、(4,3,2)、(3,3,3) |
| 10 | (4,4,2)、(4,3,3) |
| 11 | (4,4,3) |
| 12 | (4,4,4) |

同一分布可能有多种拆解方式，评分时取**最优拆解**的最大分。

## 三、门结构基础评分表

按"胡数 × 10 + 结构完整度"打分。结构完整度：句>坎>招>对>靠>单。

### 3.1 单组牌型分值（门2-7普字）

| 牌型 | 胡数 | 结构分 | 总分 |
| ---- | ---- | ------ | ---- |
| 普招（4张同字） | 6 | 40 | 100 |
| 普坎（3张同字，手牌） | 3 | 30 | 60 |
| 普坎（3张同字，组合牌） | 2 | 30 | 50 |
| 普句（3字各1） | 0 | 50 | 50 |
| 普对（2张同字） | 0 | 20 | 20 |
| 普靠（2字各1） | 0 | 10 | 10 |
| 普单（1张） | 0 | 0 | 0 |

### 3.2 单组牌型分值（门1/8精字，含上/福）

| 牌型 | 胡数 | 结构分 | 总分 |
| ---- | ---- | ------ | ---- |
| 精招（上上上上/福福福福） | 16 | 40 | 200 |
| 精坎（上上上/福福福） | 12 | 30 | 150 |
| 金对（上上/福福） | 8 | 20 | 100 |
| 精句（上大人/福禄寿） | 4 | 50 | 90 |
| 精靠（含上/福的2字） | 4 | 10 | 50 |
| 精单（上/福） | 4 | 0 | 40 |
| 银对（大人/禄寿） | 0 | 20 | 20 |
| 银靠（大人/禄寿） | 0 | 10 | 10 |
| 银单（大/人/禄/寿） | 0 | 0 | 0 |

### 3.3 门结构总分计算

```
门结构分 = 最优拆解下各组牌型分之和
```

最优拆解：遍历所有可能的句/坎/招/对/靠/单拆解组合，取总分最大的拆解方式。

## 四、跨门协同加分

手牌胡数计算中的附加胡数，对应到门结构评分中：

| 协同类型 | 胡数加成 | 分数加成 |
| -------- | -------- | -------- |
| 普对 + 句中1字（普对对应字在A集有1张） | +3 | +30 |
| 普靠 + 句中2字（普靠对应字在A集有2张） | +6 | +60 |
| 普单 + 句中2字（普单对应字在A集有2张） | +3 | +30 |
| 3精句（3个相同精句） | +6 | +60 |
| 3普句（3个相同普句） | +9 | +90 |

**注意**：金对/金靠/金单不参与跨门协同加分。

## 五、剩余牌数与进张概率

### 5.1 剩余牌数统计

每张字的总数 = 4张。剩余张数 = 4 - 已知张数（手牌+组合牌+弃牌+其他玩家组合牌）。

### 5.2 进张概率公式

```
进张概率 = 所需进张剩余张数 / 未知牌总数
```

未知牌总数 = 96 - 所有已知牌数。

### 5.3 进张概率对评分的影响

```
进张期望分 = (进张后结构分 - 当前结构分) × 进张概率
```

门结构评分 = 当前结构分 + 进张期望分（按所有可能进张累加）。

## 六、胡牌类型路线权重

不同胡牌类型对门结构评分的加成权重：

| 胡牌类型 | 触发条件 | 权重加成 |
| -------- | -------- | -------- |
| 十对 | 手牌9对 | ×1.5 |
| 黑元 | 无碰，全门2-7，无上/福 | ×1.3 |
| 红元 | 无碰无招，组1/8句≥2，上/福3-6张 | ×1.3 |
| 枯胡 | 无吃，有上/福，手牌无单无4张，6坎+1对 | ×1.2 |
| 清枯胡 | 枯胡+全门2-7 | ×1.4 |
| 清枯重台 | 清枯胡+特殊条件 | ×1.6 |
| 普通胡牌 | 总胡数≥11 | ×1.0 |

**路线判定**：根据当前手牌+组合牌结构，评估各胡牌类型的可行性，取权重最高的路线作为主路线，门结构评分乘以该权重。

## 七、吃vs摸的决策公式

### 7.1 吃牌决策

```
吃牌价值 = 吃后手牌结构总分 - 吃前手牌结构总分
        - 牌堆消耗分（吃占用1个组合牌位，-5分）
        - 摸牌机会成本（放弃1次摸牌，-8分）
        + 胡牌类型路线权重加成
```

**吃牌条件**：吃牌价值 > 0 且 吃后能进入听牌或缩短听牌距离。

### 7.2 摸牌决策

```
摸牌价值 = 摸牌后期望结构分 - 当前结构分
        + 进张概率 × 进张后结构提升
        - 被点炮风险（摸牌后需出牌，出牌可能放炮）
```

### 7.3 吃vs摸对比

```
若 吃牌价值 > 摸牌价值 → 吃牌
若 吃牌价值 ≤ 摸牌价值 → 摸牌
```

**特例**（规则game-base.md第14/16条）：
- 困难模式AI：手牌有上家出的牌且手牌中有且只有这张卡牌完整的1句，不吃，自己摸牌
- 人类玩家：同上情况不显示吃/过按钮，直接摸牌

## 八、胡数状态门槛

### 8.1 胡牌胡数条件

- 普通胡牌：总胡数 ≥ 11
- 特殊胡牌：十对、黑元、红元、枯胡、清枯胡、清枯重台（不受11胡限制）

### 8.2 胡数状态对决策的影响

| 当前胡数 | 决策倾向 |
| -------- | -------- |
| < 6 | 优先结构完整度，倾向保留对/靠进张 |
| 6-10 | 平衡结构完整度与进张概率 |
| ≥ 11 | 优先听牌距离，倾向快速听牌 |
| 已听牌 | 优先防守，避免出牌放炮 |

## 九、对手手牌预测

### 9.1 预测依据

- **弃牌区**：对手弃出的牌，说明对手不需要该字
- **组合牌区**：对手已吃/碰/招的牌，说明对手在该门有投入
- **出牌顺序**：早期出孤张，中期出多余进张，后期出防守牌
- **摸牌后出牌**：摸牌后出的牌，说明该牌对对手无用

### 9.2 预测应用

- **点炮风险评估**：出某张牌被对手吃的概率 = 对手在该门有组合牌 × 该字剩余张数 / 未知牌总数
- **防守策略**：避免出对手可能需要的字（对手组合牌所在门 + 对手未弃出的字）
- **进攻策略**：若对手手牌预测较弱（大量弃牌、无组合牌），可激进进攻

### 9.3 对手手牌预测对评分的影响

```
出牌风险分 = Σ(每个对手点炮概率 × 点炮后损失分)
出牌最终评分 = 门结构评分 - 出牌风险分
```

## 十、综合决策公式

### 10.1 出牌决策

```
对每张可出的牌：
  出牌评分 = 出牌后手牌结构总分（含跨门协同）
           × 胡牌类型路线权重
           + 进张期望分（剩余牌数加权）
           - 出牌风险分（对手预测）
           - 胡数状态调整分

选择出牌评分最高的牌打出。
```

### 10.2 吃/碰/招决策

```
操作评分 = 操作后手牌结构总分（含跨门协同）
         × 胡牌类型路线权重
         - 牌堆消耗分
         - 摸牌机会成本
         + 胡数状态调整分

若 操作评分 > 不操作评分 → 执行操作
```

## 十一、评分优先级

当多个维度冲突时，按以下优先级决策：

1. **听牌/胡牌**（最高优先级）：能听牌或胡牌时，优先听牌/胡牌
2. **胡数状态**：胡数≥11时优先缩短听牌距离
3. **门结构总分**：结构分高的拆解优先
4. **进张概率**：高概率进张优先
5. **对手预测**：高风险出牌规避
6. **胡牌类型路线**：高权重路线优先保留

## 十二、特殊规则约束

评分时必须遵守以下硬性约束（违反则评分置为-∞）：

1. **牌总数核查**（game-base.md第15条）：手牌+组合牌总张数在19-20之间
2. **招牌牌数规则**：19张不能招自己手牌4张，20张不能招别人出的牌，20张不能碰/吃
3. **单钓听点炮限制**（game-logic-rules.md第9条）：单钓听时不能胡单钓的这张字
4. **操作优先级**（game-base.md第1条）：胡>招>碰>吃
5. **困难模式AI吃牌特例**（game-base.md第14条）：手牌有完整1句时不吃
6. **低胡数普通对子保护**：胡数<8且不走黑元路线时，吃牌如果破坏普通对子（2张同字，非上/福，即普对/银对，不含金对上上/福福），不考虑吃，直接摸牌。例：手牌"丘丘己"，不吃"乙"。例外：吃后听牌时允许吃
