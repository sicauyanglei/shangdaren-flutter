一、策略总览与入口

核心设计原则

  • 操作优先级：胡 > 招 > 碰 > 吃（硬性规则）
  • 决策基础：所有决策基于"操作后总分 - 操作前总分"的最大化
  • 牌数约束：手牌+组合牌总在19-20之间；20张不能吃/碰/招别人出的牌
  • 缓存机制：听牌结果、胡数、距离、可见牌数均有缓存，避免重复计算
  • 特殊路线：十对/黑元/红元/枯胡不受"胡数≥11"限制

二、胡牌路线评估

AI在每次决策时会评估5种胡牌路线的潜力值，潜力值>0表示该路线可行：

普通胡牌（默认）
  • 条件：总胡数 ≥ 11
  • 权重：×1.0
  • 不受特殊路线限制时默认走此路线
十对路线
  • 条件：手牌9对（十对胡牌=10对）
  • 资格：发牌后≥6对 或 前3回合内出现≥6对
  • 8对以上强制走十对，不吃/不碰/不招
  • 潜力值 = 对数×80 + 进张概率×200
黑元路线
  • 条件：无碰无招，全门2-7，无上/福
  • 主动策略：门1+8张数≤3且胡数≤4时，主动清理门1/8
  • 潜力值 = 100 + 句数×50（完全黑元）
  • 主动黑元 = 50 + 句数×30 + (3-门18张数)×10
红元路线
  • 条件：无碰无招，组合牌全句，门1/8句≥2，上/福3-6张
  • 潜力值 = 80 + 特殊句数×40 + 上福数×15
枯胡路线
  • 条件：无吃，有上/福，手牌无单张无4张，6坎+1对
  • 潜力值 = 120 - 距离×30

路线对出牌策略的影响

不同路线下，胡数不足(<11)时的出牌优先级不同：

路线最优先出次优先保护
十对孤张(+250)靠单张(+150)对子(-100)
黑元孤张(+200)拆对子(+100)—
红元非门1/8孤张(+200)门1/8孤张(+100)门1/8句
枯胡单张(+200)句中单张(+120)对子(-150)、坎
普通孤张(+200)句多一张(+120)对子(-100~300)

3.2 已听牌出牌（_selectDiscardWhenTing）

核心逻辑

  1. 遍历每张手牌（跳过招4张，手牌坎3张不跳过）
  2. 模拟出牌后检查听牌结果
  3. 胡数资格保护：出牌前≥11胡，出牌后<11胡且无特殊路线 → 跳过
  4. 计算听牌进张数和进张概率
  5. 单钓听限制：单钓听的听牌数减半（点炮不可胡，只能自摸）
  6. 选择优先级：听牌数多2+ → 直接选；多1 → 胡数≥当前；相同 → 概率高→胡数高

3.5 两步前瞻（_twoStepLookahead）

逻辑

  1. 出牌后距离>5 → 返回0（太远不考虑）
  2. 遍历所有可进张的字
  3. 模拟摸到该字后的距离改善
  4. 稀缺性加成：rem=1 ×1.5，rem=2 ×1.2
  5. 累加：prob × 改善值 × 稀缺加成

6.3 招牌收益评估（_evaluateZhaoBenefit）

手牌4张同字时的评估

  1. 模拟招牌（4张移到组合牌区）
  2. 招后听牌 → 招
  3. 已听牌但招后不听 → 不招
  4. 招后19张，补摸后能否自摸 → 招
  5. 对手快听牌且招后没听牌 → 距离没改善不招
  6. 招后距离 > 招前+1 → 不招
  7. 比较招vs坎：胡数更高或距离更短 → 招
  8. 补摸改善概率>0.3 → 招
  9. 招的牌参与句组合时：
    • 缺失字剩余0 → 坎距离≤招距离时不招
    • 缺失字≤2 → 坎距离<招距离时不招
    • 缺失字>2 → 按正常逻辑

八、核心评分系统

8.1 手牌潜力评估（_evaluateHandPotentialAndDistance）

综合评估手牌的结构潜力和听牌距离，返回(potential, distance)。

potential越高表示手牌质量越好，distance越小表示越接近听牌。

8.2 门结构评分（_evaluateMenStructure）

按men-structure-score.md规则，对每门牌独立评分：

牌型门2-7（普字）门1/8（精字）
招（4张同字）100200（精招）
坎（3张同字，手牌）60150（精坎）
坎（3张同字，组合牌）50150（精坎）
句（3字各1）5090（精句）
对（2张同字）20100（金对）/ 20（银对）
靠（2字各1）1050（精靠）/ 10（银靠）
单张040（精单）/ 0（银单）

额外加成：进张期望分 = (rem/totalUnknown) × 结构提升分

8.3 胡数计算（_evaluateHuScore）

总胡数 = 组合牌胡数 + 手牌胡数 手牌胡数 = A集(句) + B集(招) + C集(坎) + D集(对/靠) + E集(单) + 附加胡数 附加胡数： a. 普对+句中1字 → +3 b. 普靠+句中2字 → +6 c. 普单+句中2字 → +3 d. 3精句 → +6 / 3普句 → +9

8.4 进张概率

进张概率 = 所需进张剩余张数 / 未知牌总数 剩余张数 = 4 - 已知张数（手牌+组合牌+弃牌+他人组合牌） 未知牌总数 = 96 - 所有已知牌数

9.1 十对听牌距离（_distanceToTingShiDui）

距离 = 9 - 对数 对数计算：4张=2对，3张=1对(+1坎)，2张=1对，1张=0 9对 = 听牌（距离0）

9.2 普通听牌距离（_distanceToTingNormal）

neededMelds = 6 - 已完成面子数(句+招+坎) 距离 = neededMelds × 2 - 有用对/靠数 - 单张可组靠数 听牌条件： 单钓听：E集1张 + D集空 → 距离=0 普通听：D集2个 + E集空 → 距离=0

使用两种模式(mode 0/1)计算取最小值：mode 0=优先对子，mode 1=优先靠

十、危险度评估（_evaluateDanger）

评估出牌被他人胡牌的风险

遍历所有对手，根据对手状态评估出牌危险度：

对手已听牌时

出牌类型残局非残局
基础危险分+25+12
精牌(上/福)+100+60
银牌(大/人/禄/寿)+40+20
同组有对手组合牌+60+40
剩余张数越少越危险（对手可能在等）

对手未听牌时

评估依据说明
对手弃牌区弃过的字→不需要，同组可能也不需要
对手组合牌区已吃/碰/招的字→该门有投入，同组其他字可能需要
对手组合牌≥3组接近听牌，危险度提高

安全出牌策略

  • 自己距离≥4时，优先出对手弃过的组的牌（safeGroupCount×15）
  • 残局时更注重防守（isLate加成更高）
  • 精牌和银牌默认更危险，出牌需谨慎

总结：AI决策优先级链

1. 能胡必胡 → 2. 能招则招 → 3. 评估碰牌 → 4. 评估吃牌 → 5. 出牌

出牌决策核心公式

出牌评分 = 手牌潜力 + 门结构变化×0.3 + 前瞻分 + 距离分×120 + 路线优先级加成(十对/黑元/红元/枯胡/普通) - 破坏句/靠惩罚 - 精银牌惩罚 - 胡数损失×50 - 危险度 + 安全出牌加成 + 预期步数×50 + 两步前瞻 选择评分最高的牌打出

关键硬性约束

  • 招（4张同字）不能出
  • 20张牌不能吃/碰/招别人出的牌
  • 19张牌不能招自己手牌的4张同字
  • 单钓听不能胡单钓的字（只能自摸）
  • 胡数≥11才能胡牌（特殊胡型除外）
  • 操作优先级：胡>招>碰>吃
